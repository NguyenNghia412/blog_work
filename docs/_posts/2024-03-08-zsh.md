### Giới thiệu
What is Zsh (Z Shell)?
Z Shell (zsh in short), is a shell just like bash. It is used as a login shell (where you get a greeting and you will type in username and password) and as a command line interpreter (where you type Linux commands such as ls, cd).

You might wonder why someone needs to switch if every shell does these two functions. One of the main reasons is that his/her’s relative experience with different shells. And another reason is that each shell has unique features such as auto-completion, frequently used commands listing, etc. Feel free to share your reason in the comments.

To learn more, refer the official page. or read an argument on why you should use zsh.

[Link tham khảo](https://linuxhandbook.com/install-zsh/){:target="_blank"}

`yum install zsh -y`

`zsh --version`

`chsh -s (which zsh) root`

Nếu `-bash: chsh: command not found` thì 

`yum install util-linux-user -y`

` chsh -s /bin/zsh` hoặc `chsh -s /bin/zsh root`

### Cài Syntax highlighting cho zsh
`sh -c "$(wget https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh -O -)"`

`git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting`

`vi ~/.zshrc`

And add zsh-syntax-highlighting in the plugins as shown:

Gõ `/` để tìm kiếm, sau đó gõ plugins để tìm tới dòng `plugins=(git)` rồi add thêm `zsh-syntax-highlighting`. Kết quả như dưới:

`plugins=(git zsh-syntax-highlighting)`

### Cài Auto suggestion cho zsh
`git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions`

Add plugin tương tự như trên, add `zsh-autosuggestions`. Kết quả như dưới:

`plugins=(git zsh-syntax-highlighting zsh-autosuggestions)`
